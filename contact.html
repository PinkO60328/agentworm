Contact

One address, and a person reads it.

No contact form, no ticket queue, no chatbot. Mail goes to one inbox and gets a reply. Pick the closest subject below and it will arrive pre-sorted, or just write directly.

Email
admin@agentwormhole.com

We answer security disclosures first, integration questions next, and everything else in order. If something is urgent, say so in the subject line and it will be treated that way.

What are you writing about?

Launchpad integration→

You run a launchpad and want every token checked before it reaches an agent. The gate, the badge and the kit are documented and free to try — mail us and we will walk through it.
Security disclosure→

You found something in the guard, the API or the registry. Send it and we will confirm receipt. Please include the version and a reproduction; we would rather fix it than debate it.
Agents and API→

Keys, pricing, rate limits, MCP setup, webhooks. Most of it is in the docs, but if the docs did not answer it that is a bug in the docs and we want to hear about it.
Anything else→

Press, research, partnerships, or a question that fits none of the above. It reaches the same place either way.
